# Aura Ambient Dashboard

An ambient Android dashboard built around a clock, greeting, live widgets and a Material 3-inspired dark interface.

## Overview
Aura is designed to turn an Android screen into a useful at-a-glance dashboard, with an emphasis on a calm layout and clear information.

## Project
- Platform: Android
- Main language: Kotlin
- Interface direction: dark theme with Material 3 styling

## Getting started
1. Clone or download this repository.
2. Open the project in Android Studio.
3. Allow Gradle to sync, then build and run on a compatible Android device or emulator.

## Development
The Android application source is maintained in this repository. Check the project files for the current implementation and build configuration.

## Status
Work in progress. Features and layout may change.
